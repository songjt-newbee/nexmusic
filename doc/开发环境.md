# 开发环境

本机实测可用的组合（Windows 10/11）。

## 必须

| 工具 | 版本 | 说明 |
|------|------|------|
| Node.js | **20.11+**（建议 20 LTS） | Vite 6 不支持 Node 16。本机若 PATH 优先是 `C:\Program Files\nodejs` 的 16，请改用 nvm：`nvm use 20.11.0`，或把 `D:\ToolSpace\nvm\v20.11.0` 放到 PATH 最前 |
| npm | 随 Node 20 即可（10.x） | 仅有 npm 8 + Node 16 不够 |
| Rust | rustc ≥ 1.77（实测 1.98） | [rustup](https://rustup.rs)，默认 host：`x86_64-pc-windows-msvc` |
| VS 2022 Build Tools | 勾选「使用 C++ 的桌面开发」 | Tauri 编 Rust 需要 `cl.exe` / `link.exe` |
| WebView2 | Win10/11 一般已带 | 登录窗和主界面都走 WebView2 |

**不需要 JDK** 就能跑桌面开发。打 Android 包时才需要 JDK 17 和 Android SDK，见下方。

## Android 打包额外需要（本机安装）

桌面那一套之外再装：

| 工具 | 版本 |
|------|------|
| JDK | **17**（`JAVA_HOME` 指向它，不要默认 21） |
| Android Studio | 稳定版 |
| SDK Platform | **36**（Android 16） |
| Build-Tools | **36.x** |
| NDK | **28**（或 27+） |
| Rust target | `rustup target add aarch64-linux-android` |

环境变量：`ANDROID_HOME`、`NDK_HOME`。命令见 [运行与打包.md](./运行与打包.md) 和根目录 README。

## 国内网络

若 rustup / crates.io 很慢，可用 rsproxy：

```
RUSTUP_DIST_SERVER=https://rsproxy.cn
RUSTUP_UPDATE_ROOT=https://rsproxy.cn/rustup
```

Cargo 镜像可写在 `%USERPROFILE%\.cargo\config.toml`：

```toml
[source.crates-io]
replace-with = "rsproxy-sparse"

[source.rsproxy-sparse]
registry = "sparse+https://rsproxy.cn/index/"
```

## 开发端口 5173

Tauri 模板默认 Vite 端口是 **1420**。在部分 Windows 上 1420 落在 Hyper-V 保留段（例如 1386–1485），会报：

`Error: listen EACCES: permission denied 127.0.0.1:1420`

本项目已改为 **5173**（[`vite.config.ts`](../vite.config.ts)、[`src-tauri/tauri.conf.json`](../src-tauri/tauri.conf.json)）。
