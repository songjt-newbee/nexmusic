# 运行与打包

## 桌面开发（当前主路径）

在项目根目录：

```bash
npm install
npm run tauri dev
```

会同时：

1. 启动 Vite：`http://localhost:5173/`
2. 编译 Rust 并打开 **390×844** 的 NexMusic 窗口

**登录、搜索、播放必须在 NexMusic 窗口里测。** 用 Chrome/Edge 打开 `localhost:5173` 只能看到静态 UI，`invoke` 会失败（没有 `__TAURI_INTERNALS__`）。

第一次编译可能要几分钟（下载 crate）。之后改 `src/` 会 HMR；改 `src-tauri/` 会重编 Rust。

## Windows 安装包

同一套环境（不用 JDK）：

```bash
npm run tauri build
```

产物在 `src-tauri/target/release/bundle/`。

## Android（本机打包，不消耗 Cursor token）

环境版本见 [开发环境.md](./开发环境.md) 和根目录 README。代码侧已接通知栏播放条，生成工程后必须打补丁：

```powershell
npm run tauri android init
powershell -File scripts/patch-android.ps1
npm run tauri android dev -- --target aarch64
# 或
npm run tauri android build -- --debug --target aarch64
```

首次在手机上播放时允许通知权限，才能在通知栏看到播放条。
