# 我喜欢：本机缓存与分类

本机缓存是「我喜欢」的准数据。登录后把当前平台喜欢列表全量落到本地；之后导出、分类、播放队列都读这份文件，不再每次只靠接口前 100 首。

## 文件在哪

和 Cookie 同一套 `tauri-plugin-store`：

- 文件名：`nexmusic-liked-cache.json`
- Windows 目录（`identifier` 为 `top.nexmusic.app`）：
  `C:\Users\<用户名>\AppData\Roaming\top.nexmusic.app\`
- 和 `music-cookies.json` 放在同一目录，**不要提交 Git**
- DeepSeek API Key 也写在这个 store 里（键 `deepseek_key`），导出 JSON **不含** Key

1300 条元数据大约 1～3 MB，本机读写不是瓶颈；慢的是分页拉列表。

## 同步

**拿不到一次返回全部。** QQ 我喜欢走 `CgiGetDiss`（`song_begin` + `song_num`），先试每页 200，失败再退回 100。网易云先拿全部 track id 再按约 50 首拉详情。酷狗按页翻。

页与页之间停 400ms，串行请求，避免并行狂刷。QQ `CgiGetDiss` 单次累计大约只能拿到约 500 首，同步会按 `total` / `hasmore` 继续翻；若仍空则用「我喜欢」真实 tid 再拉。某页失败会中断并提示「可稍后重试」；已经拉到的页会先写入，但**不会**把还没翻到的歌标成「已取消喜欢」。进度显示「已拉取 已有 / 云端总数」。

### 何时同步

1. **自动一次**：该平台登录成功，且本机还没有这个平台的 `syncedAt` → 后台全量拉取。
2. **手动「同步我喜欢」**：在官方 App 里新点赞/取消之后点一下。分类 Tab 和「我的 → 我喜欢」都能看到；显示上次时间、条数、进度。

不要做成定时自动同步，也不要每次启动都全量拉。

### 合并规则

- 行键：`平台 + 该平台歌曲 id`（如 `qqmusic:003xxx`）
- 云端有、本地无 → 新增，`sources` 为当前登录平台，标签为空
- 两边都有 → 只更新歌名/封面等展示字段，**不改**已有标签
- 本地有、云端没有 → 第一期 **不删**，打 `inLiked: false`，分类里可勾选隐藏

第一期不做：同一首歌 QQ + 网易云合成一行；播放时 QQ 优先、没资源再换平台。schema 仍预留 `sources` 数组。

## 分类 Tab

底部第三 Tab **分类**：

- 同步 / 导出 / 导入 / 规则猜测 / AI 标注
- 筛选：语言、国家、类型、风格（同时满足）
- 点歌曲即播放，走现有 `playSong`（用该行已有的平台 id）
- 铅笔按钮可手工改标签，`tagSource` 变为 `manual`

「我的 → 我喜欢」若本地已有该平台缓存，会直接展示缓存（可超过 100 首）。

## 规则猜测

不联网。用歌名/歌手字符串猜语言（日文假名、韩文、汉字、英文）、是否纯音乐/古典；语言能确定时再填国家（华语→中国等）。只填空字段，不覆盖 DeepSeek 或手工标签。可错，当垫底。

## DeepSeek

模型：`deepseek-v4-flash`，关闭 thinking，每批 20 首，只填空字段。大约 1300 首不到 1 元。

1. 在分类 Tab 粘贴 API Key 并保存（只存在本机）
2. 点「AI 标注」
3. 请求由 Rust `reqwest` 发出，不把 Key 和响应写进日志

Key 无效或余额不足会在窗口里提示。

## 导出 / 导入

- **导出**：把本机缓存 JSON 另存（含来源平台和已有标签）
- **导入**：用备份覆盖本机缓存（适合换电脑；也可重新同步）

家里电脑要继续用同一份分类，拷 `nexmusic-liked-cache.json`，或登录后点同步再重新标注。

## 验证

在 **NexMusic 窗口**（不要用 Chrome 打开 localhost）：

1. QQ 登录后自动或手动同步，条数应接近云端喜欢数
2. 导出文件里歌曲 `sources` 为 `qqmusic`
3. 改几个标签后再点同步，标签还在
4. 分类筛选后能播放

跨平台兜底不测。
