# 家里电脑接手

把仓库 clone 下来后，用 Cursor 打开项目根目录即可继续开发。

## 1. 安装环境

按 [开发环境.md](./开发环境.md) 安装：

- Node.js 20 LTS
- rustup（MSVC toolchain）
- Visual Studio 2022 Build Tools（C++ 桌面开发）

确认：

```bash
node -v    # 应 ≥ 20
rustc -V
```

## 2. 跑起来

```bash
cd <项目目录>
npm install
npm run tauri dev
```

只认弹出的 **NexMusic** 窗口，不要用浏览器打开 Vite 地址。细节见 [运行与打包.md](./运行与打包.md)。

## 3. 推 GitHub（本机已测通后）

本仓库不代为 `git push`。示例：

```bash
git init
git add .
git commit -m "Initial NexMusic desktop player"
# 在 GitHub 新建空仓库后
git remote add origin <你的仓库 URL>
git branch -M main
git push -u origin main
```

不要提交：`node_modules/`、`src-tauri/target/`、Cookie / `.env`。

家里电脑 clone 后 Cookie 和「我喜欢」缓存是空的：需要再登录，并让应用同步一次（该平台首次登录会自动拉；也可在「分类」里点「同步我喜欢」）。缓存文件在 `%AppData%\top.nexmusic.app\nexmusic-liked-cache.json`，也可以直接拷这份文件。详见 [分类标签.md](./分类标签.md)。
