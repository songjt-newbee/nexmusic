# 官方登录窗口

入口：前端 `openLogin` → `invoke("music_open_login_window")` → Rust [`create_login_window`](../src-tauri/src/music_api/mod.rs)。

## 不要用浏览器测登录

Chrome 里点「打开官方登录」会变成：

`TypeError: Cannot read properties of undefined (reading 'invoke')`

因为 `invoke` 读的是 `window.__TAURI_INTERNALS__.invoke`。请在 NexMusic 桌面窗口操作；浏览器会 toast 提示。

## 空白且关不掉

第二扇登录窗如果设置了和主窗口**不同**的 `additional_browser_args`，WebView2 会报 `HRESULT 0x8007139F`（状态不对），窗口空白、标题栏关不掉。

另外：先打开 `about:blank` 再立刻 `clear_all_browsing_data` + `navigate`，也容易把 WebView 弄坏。

当前做法：直接用目标 URL 建窗，不加额外 browser args；再点登录会先 `destroy` 旧窗。同步命令在 Windows 上建窗可能死锁，命令保持 **async**。

## Cookie

登录成功后 Cookie 写在应用本地 store（`music-cookies.json` 一类文件），不要提交到 Git。家里电脑要重新登录，不会跟着仓库走。
